# Kioo

Waitlist landing page for Kioo, a website and chatbot for Kenyan salons and barbershops.

Single file site: `index.html`. No build step.

- WhatsApp number for signups: edit `FOUNDER_WA` near the bottom of `index.html` (format 2547XXXXXXXX).
- Ad source tracking: add a tag to the link, for example `https://YOUR-NAME.github.io/kioo/#fb-ad`.
